# 🏥 AI Multi-Disease Prediction System

## 📌 Project Overview

The AI Multi-Disease Prediction System is a machine learning-based web application developed using Python and Flask. It helps predict the possibility of multiple diseases based on user-provided health parameters.

The system uses trained machine learning models to generate predictions through a simple and user-friendly web interface.

## 🎯 Objectives

- To develop an AI-based healthcare prediction system.
- To predict multiple diseases using machine learning.
- To provide a simple and interactive web application.
- To demonstrate the use of machine learning in healthcare.

## 🩺 Diseases Covered

1. Diabetes Prediction
2. Heart Disease Prediction
3. Liver Disease Prediction
4. Kidney Disease Prediction
5. Parkinson's Disease Prediction

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/Varsha-R-dev/AI_Multi_Disease_Prediction_System.git
```

### Step 2: Navigate to the Project Folder

```bash
cd AI_Multi_Disease_Prediction_System
cd AI_Multi_Disease_prediction_System
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python app.py
```

### Step 5: Open in Browser

```text
http://127.0.0.1:5000/
```
